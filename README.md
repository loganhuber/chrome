# chrome

#### Quickly opens chrome from the terminal. This script basically just runs 'open -na "Google Chrome"' with some added bookmarking options

*Open chrome*

    chrome

and a chrome window should pop up

*Set a bookmark*

    chrome -b r https://localhost:5173

*Open directly to bookmarked page*

    chrome r

*Open same page in an incognito window*

    chrome -i r

*Need to google something real quick? Use the --query flag*

    chrome -q this is the sentence Id like to google
